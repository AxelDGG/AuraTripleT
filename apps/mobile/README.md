# @norte/mobile (pendiente)

App **React Native (Expo, dev build)** para iOS/Android con el mismo estilo y funciones que la web,
más un **widget de Android** con dos accesos directos (🎤 Hablar · ⌨️ Escribir) que abren la app
directo en el chat de Norte AI vía deep link (`norteai://chat?mode=voice|text`).

Consume los mismos endpoints de `@norte/api` (`/api/dashboard`, `/api/chat` SSE, `/api/voice/*`) y
renderiza el mismo **Norte UI Spec** con componentes nativos.

Detalles y reglas en el [README raíz](../../README.md) (sección "Mobile y widget Android").
