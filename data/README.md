# data/ (pendiente)

Datos sintéticos del proyecto. **Nunca datos reales ni PII.**

- `seeds/` — seed del cliente demo para **Tiger Data** (TimescaleDB): cuentas, movimientos (hypertable),
  beneficiarios, metas. Hoy el mock vive en `packages/mcp-server/src/data/`.
- `snowflake/` — DDL, dataset poblacional sintético (miles de clientes, 24 meses), semantic model y
  scripts Cortex AI para **benchmarks de pares**.

Ver [README raíz](../README.md), sección "Retos MLH".
